本工具專為 Windows 64-bit (x64) 系統設計。若你是從 GitHub 複製專案，請直接跟隨下方傻瓜三步驟完成部署！


超簡單三步驟安裝（照著檔名按就對了）
------------------------------------------------
進到 resources\AhYooVideoBackup\ 資料夾後，請依序執行：

第一步：雙擊「打包.exe 步驟1.bat」
作用：自動檢查 Python 環境，並將 Desktop App 打包成 64-bit 的獨立 .exe 執行檔。

第二步：雙擊「install 步驟2.bat」
作用：建立系統安裝資料夾、自動複製打包好的 EXE 檔案，並註冊 Chrome / Edge 的 Native Messaging Host 服務。
注意：過程中會詢問你的 Extension ID。
(可在 chrome://extensions/ 找到你載入的擴充功能，裡面會有「ID」字樣與一串英數代碼。
如果沒有顯示，請確保有開啟右上角的「開發人員模式」
→ 點擊「載入未封裝項目」
→ 選取 ..\resources\AhYooVideoBackup\extension
→ 在 chrome://extensions/ 畫面找到「阿柚自動影片備份 1.0」
→ 複製下方那串英文數字。很重要！如果輸錯就完全壞掉神仙也無法救你，只能重新執行 install 步驟2.bat)

第三步：雙擊「下載影片一定要先下載我 步驟3.bat」
作用：自動從官方下載並解壓縮免安裝版 ffmpeg.exe，並直接同步複製到系統安裝目錄中，確保高畫質影片與音訊合併轉檔功能正常。


瀏覽器擴充功能（Extension）載入方法
------------------------------------------------
1. 開啟 Chrome 瀏覽器，網址列輸入 chrome://extensions（Edge 請輸入 edge://extensions）。
2. 開啟右上角的「開發人員模式」。
3. 點擊「載入未封裝項目」，選擇專案中的「extension」資料夾。
4. 複製畫面上顯示的 Extension ID，在執行 install 步驟2.bat 時貼上即可完成綁定！

已知問題與注意事項 (Troubleshooting)
------------------------------------------------
* 擴充功能報錯 File path cannot be resolved？
  原因：安裝時系統會綁定當時的「資料夾完整絕對路徑」。若後續修改了上層資料夾名稱（例如修改了 automatic-video-backup-tool），瀏覽器會找不到 manifest.json。
  解法：請勿隨意修改資料夾名稱（參照根目錄 檔案資料夾不要改名稱.txt）。若已改名，請重新執行一次「install 步驟2.bat」重新寫入最新路徑即可。

* 為什麼影片抓下來沒有聲音或無法合併 (提示錯誤無法下載影片)？
  解法：請確定有點擊執行「下載影片一定要先下載我 步驟3.bat」，讓系統自動下載並配置 ffmpeg.exe。

* 打包時跳出錯誤提示「Python 是 32-bit」？
  解法：本專案強制要求 64-bit 環境。請至 Python 官網下載安裝 python-3.x.x-amd64.exe 後重新執行步驟 1。

* 為什麼一直跑出同一部影片，不抓取當前播放的影片？
  解法：請前往 chrome://extensions/，找到該擴充功能按下「重新載入」按鈕，最後刷新影片網頁頁面 (F5) 即可恢復正常。
